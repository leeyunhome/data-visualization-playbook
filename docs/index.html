Data Visualization

데이터 시각화 포트폴리오

인프런 32가지 데이터 시각화 전략 - 비전공자를 위한 기초이론 & 실습 (반병현) 강의에서 배운 차트 기법을 실습용 예제 데이터가 아니라 개인 프로젝트에서 실제로 만든 데이터에 적용해본 결과를 모아둔다. 강의 진행 노트(주피터 노트북)는 별도로 관리하고, 여기에는 실제 데이터로 재현한 결과만 정리한다.

히스토그램 · KDE · 쌍 비교

신뢰도는 차이 없고, 검출 수만 체계적으로 적다

토마토 온실 씬을 3D Gaussian Splatting으로 재구성한 뒤, 동일 시점 실촬영·렌더 24쌍에 같은 검출기를 돌린 결과. 두 분포를 겹쳐 그리면 "비슷하다"로 끝나지만, 쌍을 살려서 보면 24쌍 중 23쌍에서 렌더가 같거나 적다는 일관된 방향이 드러난다.

 Python · seaborn · CLI

Python을 사용한 시각화

CSV를 던지면 박스플롯·히스토그램·ECDF를 뽑아주는 CLI를 만들고 실제로 돌렸다. 세 그래프 모두 "차이 없다"고 말하지만, 같은 데이터를 쌍으로 보면 결론이 뒤집힌다 — 주변분포만 보는 것의 한계.

 Strip · Box · Violin · Swarm

표본 크기에 따라 달라지는 분포 시각화

같은 데이터라도 점이 3,000개면 strip plot이 덩어리가 되고, 150개면 다시 읽힌다. CSV를 올려 네 가지 표현을 바꿔가며 비교하는 도구.
강의 출처: 인프런 32가지 데이터 시각화 전략 (반병현) · 데이터·코드: field2scene
